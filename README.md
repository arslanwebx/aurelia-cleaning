# Sugar In The Morning Cleaning Service

Static single-page website prepared for GitHub and Vercel deployment.

## Deploy with Vercel

1. Create a new GitHub repository.
2. Upload all files from this folder to the repository root.
3. In Vercel, select **Add New → Project**.
4. Import the GitHub repository.
5. Leave the framework preset as **Other** and click **Deploy**.

No build command or environment variables are required.

- `index.html` — complete website with embedded CSS and JavaScript
